NeuroSort AI v1.0

Intelligent File Organization

Powered by DSA algorithms in C and AI Expert System with heuristic scoring — designed for students, built for everyone.

📁

💡 How it works: Enter any messy folder path → NeuroSort AI scans it using BFS, classifies files with 25 expert rules, sorts with auto-selected algorithm, detects duplicates via hash table, and shows Before/After results.

⚙️ CLI mode: neurosort.exe "C:\Downloads" → generates report.json → load it in the Report tab.

📂 Or browse a folder to scan files directly in the browser
